# devtimer

Minimal Pomodoro focus timer for developers. Built with WPF and .NET 8.

I kept losing track of focus blocks while coding, so I built a tiny timer that does exactly one thing well — no accounts, no cloud, no clutter.

## Features
- 25 / 5 / 15 minute modes (Focus / Short break / Long break)
- Auto-advances to a break after each focus session
- Long break every 4th session
- Session counter
- Pause & reset

## Requirements
.NET 8 SDK + Windows

## Run
```bash
dotnet run --project DevTimer
```
